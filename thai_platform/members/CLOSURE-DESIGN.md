# 계정 비활성화와 삭제 검토

## 확정된 처리

- 회원은 내 계정에서 별도 확인란과 CSRF 보호 POST로 계정을 비활성화한다.
- 요청과 동시에 로그인이 막히고 현재 세션을 종료한다.
- 질문·답변은 유지한다. 회원과 콘텐츠를 삭제하지 않는다.
- 운영자 화면에는 요청 시각·계정 식별자·검토 상태가 표시된다. 운영자는 검토 완료로 표시할 수 있지만, 이 동작은 계정이나 콘텐츠를 삭제하지 않는다.
- 이메일·Google 계정 접근을 잃은 경우 각 제공자의 복구 흐름만 사용한다. 별도 신원 확인 절차가 확정되기 전에는 수동 복구 기능을 제공하지 않는다.

## 중요한 미완료 사항

회원의 실제 영구 삭제는 구현하지 않았다. 게시물·댓글·신고가 사용자 행 삭제를 막도록 `PROTECT` 관계가 있다. 기존 콘텐츠를 익명화할지, 삭제할지, 어떤 기록을 어느 기간 보관할지 정해지지 않았으며 법률 검토도 필요하다. 운영자는 삭제 검토 절차와 처리 결과 기준을 별도로 확정해야 한다. `reviewed` 상태는 실제 삭제 완료를 뜻하지 않는다.

검토가 끝난 계정을 다시 활성화하는 절차도 아직 정해지지 않았다. 계정 비활성화 요청은 사용자가 로그인할 수 없게 하므로, 복구 승인 절차를 결정하기 전에는 운영자 수동 재활성화가 허용된 것으로 해석하지 않는다.

## 검사

`members.tests_closure`는 확인 미선택 거부, CSRF 거부, 계정 비활성화와 세션 종료, 콘텐츠 보존, 운영자 검토 기록 및 삭제 비수행을 검사한다. 운영 데이터에는 마이그레이션을 적용하지 않는다.
