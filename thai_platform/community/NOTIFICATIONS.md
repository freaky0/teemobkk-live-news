# 사이트 내 알림

## 동작

- 다른 회원이 공개 질문에 답변하면 질문 작성자에게 `reply` 알림을 만든다. 작성자의 자기 답변은 알림을 만들지 않는다.
- 신고가 접수되면 활성 운영자에게 `moderation_report` 알림을 만든다. 신고가 실제로 처리 상태로 변경되면 신고자에게 `report_update` 알림을 보낸다. 같은 상태를 다시 저장해도 알림은 추가하지 않는다.
- 알림에는 답변 본문, 질문 제목, 신고 상세를 복사하지 않는다. API는 관련 객체 식별자만 반환한다. 웹 화면은 일반 문구로 표시한다.
- `GET /api/v1/notifications/`는 로그인된 활성 계정만 조회 가능하며, 본인 알림만 페이지 단위로 반환한다. `POST /api/v1/notifications/{id}/read/`는 본인 알림만 읽음 처리한다. 타인의 알림은 404로 응답한다.
- 로그인 사용자는 `/community/notifications/`에서 최근 50개를 보고 CSRF 보호 POST로 읽음 처리할 수 있다. 화면과 API 응답은 비공개 캐시 금지 헤더를 사용한다.
- 모바일 클라이언트는 같은 API를 소비할 수 있다. 푸시·이메일 발송은 포함하지 않는다.

## 검증

`community.tests_notifications`는 새 답변 통보, 신고 접수·처리 통보, 민감 본문 비노출, 사용자간 읽음 권한 격리, 웹 페이지를 확인한다. 사용자 데이터가 없는 테스트 DB로 실행한다.
