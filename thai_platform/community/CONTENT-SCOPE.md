# 가이드·긴급 안내·통합 검색·이미지: 범위 초안

이 문서는 현재 코드에서 확인한 기능과 다음 구현을 위한 제안을 분리한다. 아래 제안은 승인 전까지 확정 사양이나 실서비스 기능이 아니다. 운영 데이터나 실제 긴급 연락처를 이 문서에서 만들어내지 않는다.

## 현재 코드에서 확인한 기능

- `Post`는 제목·본문 텍스트, 지역, 분류, 해결 상태, 게시 상태를 저장한다. 모델과 폼에서 이미지 파일 필드는 찾지 못했다.
- 커뮤니티 검색은 공개 게시글의 제목·본문을 대상으로 한다. `q`, 지역, 분류, 해결 상태를 커뮤니티 목록 안에서 필터링한다.
- 뉴스는 별도 `POST_NEWS_DB` SQLite 연결을 통해 읽기 전용으로 조회한다. 뉴스 목록에는 뉴스 자체의 `q` 검색이 있다. 커뮤니티와 뉴스는 서로 다른 URL·조회 경로를 사용한다.
- 가이드, 긴급 공지, 통합 검색, 이미지 업로드에 해당하는 별도 모델·경로·파일 업로드 처리는 현재 코드에서 확인되지 않았다.
- 기존 지역·분류 값은 방콕·치앙마이·푸껫·공통과 생활·주거·비자·교통·여행·은행이다. 이를 가이드 우선순위나 긴급 공지 분류로 자동 해석하지 않는다.

## 구현 제안

### 가이드

편집 가능한 가이드 페이지와 출처·최종 확인일을 함께 저장한다. 공개 전 검토를 거치고, 출처가 바뀌면 업데이트할 담당자와 절차를 정한다. 비자·주거·은행 등의 실제 내용은 사용자가 지정하거나 승인한 신뢰 가능한 자료가 있어야 작성한다. 법률·의료·재난 조언으로 오해될 문구는 별도 검토한다.

### 긴급 안내

커뮤니티 글과 별도인, 운영자가 직접 게시하고 해제하는 알림 영역을 제안한다. 시작·종료 시각, 출처 링크, 확인자, 게시 상태를 남기고 자동 생성·자동 게시하지 않는다. 공식 연락처나 정부 안내는 최신 원문과 적용 지역을 확인한 뒤에만 표시한다. 누가 게시·수정·종료할지와 긴급 상황에서 확인할 대체 담당자를 정해야 한다.

### 통합 검색

한 검색 화면에서 공개 뉴스, 공개 커뮤니티 게시글, 승인된 가이드를 검색하는 방안을 제안한다. 각 결과에는 종류와 원문 상세 링크를 표시한다. 신고 세부, 비공개 스크랩·알림, 회원 식별 정보는 검색 대상에서 제외한다. 댓글까지 검색할지, 긴급 안내를 검색 결과에 넣을지, 정렬·페이지 통합 방식은 별도 결정이 필요하다. 뉴스 DB는 계속 읽기 전용으로 두고, 두 DB를 한 SQL 쿼리로 묶지 않는 구조를 권장한다.

### 이미지

업로드를 허용하기 전에 파일 저장소와 접근 방식, 파일 형식·크기·개수 제한, 보관·삭제 기준, 신고·저작권 처리 방식을 정한다. 권장 보안 기본값은 래스터 형식 허용, SVG 차단, 서버에서 파일명 재생성, 이미지 재인코딩으로 메타데이터 제거, 크기 제한, 공개 웹 루트 밖 저장이다. 이 값과 저장소는 아직 선택되지 않았다.

## 구현 전에 필요한 자료와 결정

- 첫 가이드 주제와 각 주제별 공식 원문 URL, 언어, 적용 지역, 최종 확인 날짜, 수정 책임자.
- 긴급 안내의 승인된 공식 출처·연락처, 게시 권한자와 대체 담당자, 종료 기준.
- 통합 검색에 포함할 공개 자료 종류, 댓글 포함 여부, 결과 정렬·페이지 동작.
- 이미지 업로드 대상(게시글·댓글), 허용 형식·크기·개수, 저장 위치, 보관 기간, 이미지 삭제·신고·권리 확인 절차.
- 실제 회원 이미지의 공개 범위와 외부 CDN 사용 여부. 브랜드 파일·저장소 제공자는 확인 전 가정하지 않는다.

## 검증 경계

현재 확인은 격리된 개발 브랜치의 코드와 문서에 한정된다. 실제 운영 사이트에서 이 네 기능이 전혀 없다는 뜻은 아니며, 그 배포본은 여기서 확인하지 않았다. 이 문서는 범위 초안이며 구현·브라우저 검수·운영 반영 완료를 뜻하지 않는다.
