# 태국 커뮤니티 약관·개인정보 안내 기준 조사

작성일: 2026-10-26
대상: TEEMOBKK POST 공개 커뮤니티 가입 전 정책 검토
상태: 자료 검토 및 사이트 맞춤 초안. 법률 자문이나 공개 승인 문서가 아님.

## 법률 기준과 공공기관 안내

태국 PDPA B.E. 2562의 2019년 영어 번역본은 개인정보 수집 전에 목적, 법률·계약상 제공 필요성, 수집 항목·보유기간, 수신자 범주, 처리자 연락처, 정보주체 권리를 알리도록 규정한다(제23조).[1] 제30조는 접근·사본 요청을 원칙적으로 지체 없이 처리하고 30일을 넘기지 않도록 한다. 제37조는 적절한 보안조치, 보유기간 종료·목적 달성 후 파기 체계, 개인정보 침해 통지 의무를 규정한다.[1] 이 문서는 MDES가 게시한 **비공식 영어 번역**을 참고한 것이며, 태국어 원문과 시행 규정이 우선한다.

태국 PDPC의 정부 플랫폼 GPPC 개인정보 안내는 처리자·범위, 수집 정보, 수집 경로, 목적, 외부 제공자, 국외 이전, 보안, 보유기간, 정보주체 권리, 변경 고지로 내용을 나눈다.[2] 이 구성을 TEEMOBKK POST에 적용하되, 공공기관용 주소·담당자·공공서비스 항목은 복사하지 않는다.

## 커뮤니티 이용약관의 비교 사례

Stack Overflow 공개 네트워크 약관은 비회원 열람자와 회원 모두에게 약관이 적용된다는 점, 이용자 의무, 공개 콘텐츠 권한, 운영 조치, 보증 부인과 변경 절차를 구분한다.[3] 다만 해당 약관의 강제 중재·집단소송 포기, 공개 콘텐츠의 CC BY-SA 조건은 TEEMOBKK POST의 규모·운영 방식에 맞지 않아 가져오지 않는다.

Reddit 이용자 약관은 이용자가 콘텐츠 소유권을 유지하면서 플랫폼에 이용 허락을 주는 구조와 금지 행위·운영 제한을 별도 항목으로 둔다.[4] Reddit의 광범위하고 지속적인 라이선스는 복사하지 않는다. TEEMOBKK POST 초안은 서비스 저장·전달·표시·보안·백업에 필요한 좁은 범위의 비독점 이용 허락만 둔다. 광고·외부 사업·AI 학습 권리는 포함하지 않는다.

Reddit 개인정보 안내는 계정 정보, 공개 콘텐츠, 비공개 신고·문의, 사용 기록·로그, 쿠키 및 제3자 통합을 나눠 설명한다.[5] 이 분류 방식만 참고하고, Reddit의 광고·추론 정보·IP 보유기간은 기능과 설정이 다른 TEEMOBKK POST에 적용하지 않는다.

## TEEMOBKK POST에 적용한 항목

- 서비스는 태국 생활 정보와 공개 질문·답변을 다루며, 공개 글은 로그인 없이 읽고 회원 기능은 이메일 인증 또는 Google 로그인 뒤 사용한다.
- 회원 이메일과 공개 닉네임·게시물을 구분한다. 공개 게시물·답변·댓글과 표시 이름은 외부에 보일 수 있고, 신고 정보는 비공개 운영 자료다.
- 회원은 자기 콘텐츠 권리를 보유한다. 서비스 제공에 필요한 저장·표시·전달·보안·백업 외의 광고·상품화·AI 학습 라이선스는 주지 않는다.
- 신고 수만으로 위반을 확정하지 않고, 서로 다른 계정 10개 신고 시 검토 동안 임시 숨김이 가능하다는 실제 동작을 적는다.
- Google 비밀번호를 수집하지 않고 이메일 주소가 같다는 이유로 계정을 자동 연결하지 않는 현재 동작을 적는다.
- 뉴스 이미지가 브라우저에서 외부 호스트로 직접 요청되는 점과 현재 확인된 호스트를 알린다. 메일·호스팅 업체, 로그, 백업, 국외 처리 정보는 아직 검증되지 않아 공개 전 차단 항목으로 남긴다.
- 사용자 승인 목표인 계정 식별정보 7일 삭제, 종료된 신고 기록 90일 정리, 보안 로그 최대 3개월을 초안에 분리해 적었다. 자동 삭제·예약·서버 설정이 검증될 때까지 실제 운영 보장으로 공표하지 않는다. 백업 보유기간은 정해진 근거가 확인되지 않아 비워 둔다.
- 가입 가능 연령, 적용 법률·관할, 요청 처리·신고 이의 절차와 시행일은 확인되지 않아 비워 둔다. 임의의 미국식 13세 기준, 강제 중재, 보편적 면책 조항은 넣지 않는다.

## 공개 차단 조건

`POST_POLICY_APPROVED=0` 및 `POST_RESTRICTED_PREVIEW=1` 상태를 유지한다. 이 파일들과 `docs/policy-draft/terms.txt`, `docs/policy-draft/privacy.txt`는 검토 초안이다. 공개 가입을 열기 전 실제 메일·호스팅 업체와 처리 국가, 운영자 연락 주소 또는 법령상 대표자 표시 요건, 로그·백업 만료, 7일 계정 삭제 절차, 신고 기록 90일 정리 예약, 적용 법률과 연령 조건을 확인하고 운영자가 최종 문안과 시행일을 승인해야 한다. 초안 수정은 운영 서비스에 게시된 변경이 아니다.
